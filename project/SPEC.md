# Contributing to OpenRig

This project is work on OpenRig itself, done from your clone of the openrig
repository. The lead turns one issue into one pull request with an honest
description, and you decide when it is pushed. Merging, releases and maintainer
decisions stay with the openrig maintainers.

The repository's maps are ARCHITECTURE.md, docs/as-built/arteries.md,
docs/as-built/test-layers.md and its `developing-openrig` skill. The
`openrig-world` context pack holds the project's identity, workflow and craft.
Every map can be stale: the code and its behaviour decide.
