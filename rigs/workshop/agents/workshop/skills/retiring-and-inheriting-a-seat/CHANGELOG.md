# Changelog — retiring-and-inheriting-a-seat

The skill carries the current handover practice. This changelog records public
mechanism and wording changes without substituting local experiments for product
verification.

## 2026-08-13 — record the wake surface and actionable reach-back instructions

`rig ask --wake`, introduced in CLI 0.5.1, provides explicit bounded consultation
of a retained session. The packet guidance therefore includes the exact resume
handle and questions that only the predecessor can help answer. Check current
`rig ask --help` for runtime selection and timeout options.

A predecessor's answers are testimony; that does not mean its retained history
became unavailable at retirement. Record the history's actual location and known
limits. If the wrapper cannot answer, distinguish missing history, runtime failure,
timeout and context exhaustion; use a supported runtime resume path only when
its prerequisites and the requested authority permit it.

Give the successor triggers for consultation, such as an unexplained tradeoff or
conflicting artifact, instead of requiring a consultation count. This rationale
is not a current end-to-end wake test or proof of successor behavior.
