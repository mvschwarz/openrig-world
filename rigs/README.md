# Rig bundles

[Workshop](workshop/README.md) is the small software team: install it once as
`workshop` in `~/rigs/workshop`. Its configurations describe runtime choices
for the installing agent to match to your available logins, not separate rigs.

Two retained reference bundles are also available:

- [factory-rsi](launch/factory-rsi/README.md): the seven-seat recursive improvement factory.
- [secrets-manager](launch/secrets-manager/README.md): a Vault development service and specialist.

The `launch/` level preserves these references' original relative agent imports.
Their original product specs remain in `world-bundle.yaml`; `rig.yaml` is the
installable entry point. Registry views describe the packaged bytes. Neither a
listing nor a validation/plan result proves a native runtime journey.
