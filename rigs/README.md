# Rig bundles

[Workshop](workshop/README.md) is the small software team: install it once as
`workshop` in `~/rigs/workshop`. Its configurations describe runtime choices
for the installing agent to match to your available logins, not separate rigs.

[factory-rsi](launch/factory-rsi/README.md) is also available as a retained
reference: the seven-seat recursive improvement factory.

The `launch/` level preserves its original relative agent imports.
Its original product spec remains in `world-bundle.yaml`; `rig.yaml` is the
entry point. Registry views describe the packaged workshop and factory-rsi bytes. Neither a
listing nor a validation/plan result proves a native runtime journey.
